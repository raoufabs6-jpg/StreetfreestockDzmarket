# ملفات العرض

- **Calisthenics_AR.pptx**: العرض الرئيسي، 15 شريحة عربية قابلة للتعديل مع ملاحظات المتحدث.
- **Calisthenics_Slide_Guide_AR.md**: محتوى كل شريحة، وصف الصورة والمخطط، ملاحظات الشرح والمصادر.
- **slide_content.json**: نسخة منظمة من المحتوى لإعادة الاستخدام.

افتح ملف PowerPoint واستبدل `[اسم مقدم العرض]` في الغلاف. لمراجعة الشرح افتح جزء **Notes** أو **Presenter View**.

إعادة توليد العرض: `pip install python-pptx Pillow` ثم `python scripts/build_presentation.py` من جذر المستودع.

التدريب الوارد مثال تثقيفي عام للبالغين الأصحاء، وليس برنامجًا علاجيًا فرديًا. الصور واقعية من Pexels وروابطها في دليل العرض.
